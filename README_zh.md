# tome-distill

**tome-distill** 是一个采用 **Apache-2.0** 协议的开源工具包，专注于**双栏/多栏辞书、语法与规则手册、行业术语汇编、地方志等高密度条目型工具书在初步 OCR 之后的结构校验、辅助精校、跨文献知识库编译与上下文预算检索**。

> **工具边界**：`tome-distill` **不替代** `MinerU`、`olmOCR`、`Docling` 等前端通用整页识别工具，而是承接在初步 OCR 文本与原始 PDF 之后，专门解决高密度工具书入库时“漏词发现不了、分栏读串、生僻字改写、精校改坏旧字段、多本书口径冲突以及检索误触发塞满上下文”等工程难题。

---

## 为什么做这个工具（解决什么问题与适用场景）

单栏学术论文或普通文档经通用 OCR 即可获得不错结果，但面对**双栏词典、语法与规则手册、专业词表以及地方志词汇卷**等条目型工具书时，工程落地常遇到四个断点：

1. **分栏串读与隐蔽漏抽难以自证**：多栏页面容易发生横向跨栏混读，且整本数百页文献在 OCR 或大模型抽取后常会整段遗漏词条，单看生成的 JSON 文本几乎无法察觉到底漏了哪一页、哪一栏。
2. **全页喂给多模态大模型代价高、字段校对易回归**：直接把高分辨率整页扫描图不断送给视觉大模型不仅成本高、容易超出单次请求包体上限导致超时，而且让模型整卡重写 JSON 时经常不小心改丢原本正确的例句或读音；如果依赖 AGPL 许可的 PDF 渲染库，又会给商业或 Apache-2.0 项目带来合规阻碍。
3. **生僻字、简繁异体与跨书分歧处理棘手**：普通简繁转换会把部分需要保留辨义的专用本字或古字一并归并，导致字符长度变化或词源失真；多部词典对同一词条用法存在不同考证时，简单“投票覆盖”会丢失重要学术依据。
4. **检索阶段单字高频误命中，快速挤占 Prompt 窗口**：如果直接按关键词检索词库，像普通双音节词里的某个常见单字会误触发大量单字虚词/助词词条，把大模型宝贵的上下文预算填满无关条目。

**典型适用场景**：
- 为机器翻译、翻译评测、语言教学或垂直问答构建**可溯源的多源词典/语法知识库**；
- 复杂版面工具书数字化后的**零漏条核验、局部看图精校工作流**；
- 需要严格控制 Prompt Token 预算、并避免常见词汇误触发长尾词条的**确定性轻量检索增强（Sparse RAG）**。

## 处理流程与各步骤实现逻辑

```text
输入：初步 OCR 文本 + 原书 PDF (可选) + YAML 领域配置 (DomainProfile)
   │
   ├─► [1] 目录闭合检查与多栏版面核验 (toc.py, adapters.py)
   │        └─ 行号区间完整性校验、双栏坐标重排、页眉起止词头 × 书末索引交叉核对
   │
   ├─► [2] 存疑区域局部切图拼图 [可选] (pdf_render.py, ocr_helper.py)
   │        └─ pypdfium2 按坐标裁切疑点页眉/词条窄条，压缩为轻量灰度 JPEG 拼图辅助复核
   │
   ├─► [3] 双层卡片建模与字段级增量补丁校对 (schema.py, field_diffs.py)
   │        └─ 推理内容与文献溯源分离、防元信息泄漏扫描、隔离抽/校的轻量微补丁更新
   │
   ├─► [4] 正字保护归一与多源词条编译 (text_utils.py, compiler.py)
   │        └─ 1:1 保护字简繁归一、并查集跨书聚类、分歧并存、触发规则安全校验
   │
   └─► [5] 复合词掩码与预算受限检索 (retriever.py, zh_compounds.py)
            └─ 屏蔽通用复合词误命中 + 分级槽位/字符上限分配 -> 输出紧凑模型上下文
```

### 各步骤核心方法设计

#### 步骤 1：确定性结构与多栏版面核验（`toc.py`、`adapters.py`）
- **目录行号闭合校验（`toc.py`）**：在进入昂贵的大模型处理之前，先核查目录树各节点的行号区间是否严格覆盖全文（支持单栏连续划分 `strict_line_partition` 与双栏/多栏并集闭合 `multicolumn_line_union`），提前暴露未切分、越界或行号重叠的章节。
- **双栏坐标重排与页眉 × 索引交叉检查（`DoubleColumnDictAdapter`）**：利用文本框边界框（BBox）计算栏间距，自动将横向串读的内容按“先左栏自上而下、再右栏自上而下”重新理顺；同时利用工具书固有的编排约束——比对每页顶部页眉标注的起止词头（如 `[甲 ... 乙]`）、正文实际抽出的词头与书末总索引，无需消耗模型 Token 即可定位存在漏抽或跳栏的页码。其他版面可通过继承 `LayoutAdapter` 拓展。

#### 步骤 2：面向人眼与视觉模型的局部窄条裁切（`pdf_render.py`、`ocr_helper.py`，可选）
- **纯宽松许可 PDF 光栅化**：基于 **Apache-2.0 / BSD 许可的 `pypdfium2`** 替代 AGPL 类库实现 PDF 渲染，扫除许可传染风险。
- **精准裁切与体积自适应压缩**：只针对第 1 步标出的存疑页面或生僻字符所在坐标块做局部裁切，经亮度阈值漂白底噪后，加上清晰数字标签纵向拼接为灰度 JPEG 条带图（通过自适应缩放与质量阶梯压缩将单图体积默认控制在 `215 KB` 内），既方便人工集中扫视核对，也能让视觉大模型低成本、高清晰地看图确认细节；另可选配合 `RapidOCR` 辅助页眉识别。

#### 步骤 3：内容层与溯源层分离 + 字段级微补丁校对（`schema.py`、`field_diffs.py`）
- **双层卡片结构与干净度防护**：每张词条卡片物理划分为两部分：
  - `judge_view`（**推理可用层**）：面向下游大模型的干净释义、读音、例句与语法边界，自动拦截“第 X 页”、“原书未单列”、“`U+XXXX`”等编校说明文字误混入模型提示词；
  - `provenance`（**文献溯源层**）：保留书名、页码、原书逐字引文以及抽取者/复核者记录，确保每条知识可回查原书；
  - 序列化输出前先递归扫描原始字符串，拦截隐藏控制字符（如 `\x07`）并校验归并前后记录数守恒。
- **分离抽取与复核的轻量微补丁（`field_diffs.py`）**：复核环节强制校验复核人不同于初抽人，并采用**字段级增量补丁**（只提交 `updates` 修改个别字段、`insert_after` 在指定锚点后补插漏条并按 `B..Z -> AA, AB...` 连续自动编号、`delete_ids` 移除误抽），避免重写整张 JSON 破坏原有正确信息；同时内置按来源与分类的分层随机盲抽辅助质检。

#### 步骤 4：正字保护简繁归一与多源词条编译（`text_utils.py`、`compiler.py`）
- **1:1 字符位置不变的保护词转换（`text_utils.py`）**：基于 YAML 中指定的 `protected_chars` 保护字表执行 OpenCC 简繁归一——指定保护的方言本字或古字原样保留，其余字符做等价转换并严格保证转换前后字符串长度 1:1 一致，使匹配偏移量与原文严丝合缝。
- **跨书聚类与学术分歧并存（`compiler.py`）**：用并查集（Union-Find）将多家辞书中同一词条的不同表述归并为统一检索入口，自动双向补全“参见”互见引用；遇到不同书籍对某词音义或本字看法相反时，保留双方证据并显式建立互指冲突记录，而非简单覆盖。同时在编译阶段对可选自定义正则规则执行安全检查（禁止 `.*` 等过度宽泛匹配），输出分级压缩的紧凑条目文本与多键倒排索引。

#### 步骤 5：通用复合词掩码与上下文预算检索（`retriever.py`、`zh_compounds.py`）
- **消除单字拆字误报（`retriever.py`、`zh_compounds.py`）**：在扫描句中的单字功能词或方言词之前，先用通用现代汉语多字复合词表（可用 `[compounds]` 扩展从参考语料/词库统计自动生成，或传入外部词表）对句子中构成的常规词组打上字符掩码——从而避免常见双音节词里的单个汉字误触发无关单字语法条目，同时允许专门配置在句尾/词尾例外放行的粘着助词。
- **多模式锚点与分级预算控制**：
  - 支持仅按源语词形检索（`dialect_only`）、借由标准语多字实词反向查锚点（`standard_anchor`），或对比待改草稿与当前句差异片段做局部重点加权（`hybrid`）；
  - 在预设的卡片数量与字符数上限下执行分级分配（`budgeted` 策略）：优先保证硬性用法禁忌与冲突提示，随后为关键语法功能词与分类小类设置独立槽位上限以防单个高频词霸屏，再将剩余上下文预算留给高相关性实词与熟语，也可切换为 `longest`（最长匹配优先）或 `full`（全量召回）。

## 安装与快速开始

### 1. 安装

核心引擎安装（纯 CPU，零 PDF / OCR 依赖，仅需 Python ≥ 3.11、`PyYAML` 与 `opencc-python-reimplemented`）：

```bash
pip install -e .
```

按需安装可选扩展：

```bash
pip install -e ".[pdf]"        # 启用基于 pypdfium2 + Pillow + NumPy 的局部切图拼图 (纯宽松许可)
pip install -e ".[ocr]"        # 启用 RapidOCR + OpenCV 页眉与窄栏辅助识别
pip install -e ".[compounds]"  # 启用基于 jieba 的通用复合词屏蔽表统计生成
pip install -e ".[all]"        # 安装以上全部可选扩展
```

### 2. 运行端到端玩具辞书示例（零真实书稿）

示例脚本会自动用程序生成 1 页完全虚构的“星光玩具词典”双栏 PDF 与 10 张原创虚构词条卡，完整串跑 PDF 页眉与栏位检测、局部 JPEG 裁切、目录闭合、微补丁更新、编译校验与预算受限检索（需先安装 `.[pdf]`，在 Windows PowerShell 下先执行 `$env:PYTHONPATH="src"`）：

```bash
# 1. 运行端到端玩具词典流水线示例
PYTHONPATH=src python examples/run_toy_pipeline.py --work-dir demo_out

# 2. 运行全套标准库 unittest（涵盖零 AGPL AST 校验、控制字符拦截、1:1 正字保护、检索验证等）
PYTHONPATH=src python -B -m unittest discover -s tests -v
```

## 配置与迁移至新文献（`DomainProfile`）

仓库内置了一份完全中立、零领域硬编码的配置模板 [`profiles/generic_profile.yaml`](./profiles/generic_profile.yaml)。迁移到新的语种、方言或专题参考书目时，无需修改引擎源码，复制该 YAML 文件后按需填入以下板块即可：

- **文献与分类体系（`profile_meta` / `sources`）**：定义目标语种标识、目标知识表名称、自定义语法/词汇层级分类树（`taxonomy_tree`）及源文献/隔离评测路径配置。
- **正字保护与清洗规则（`text_normalization`）**：配置简繁转换模式（`opencc_config`）、不可强制合并的专字列表（`protected_chars`）、行内夹注模式与禁止进入下游模型层（`judge_view`）的编校元信息正则。
- **PDF 裁切与压缩参数（`pdf_render`）**：设定渲染 DPI、灰度条带宽度、页眉及分栏归一化裁切框（`header_norm_box`、`preset_norm_boxes`）、降噪阈值与单图字节上限（`max_img_bytes`）。
- **版面解析与编译阈值（`layout_adapter` / `compiler` / `gates`）**：配置分栏最小栏距、跨源归并相似度阈值、不同类别卡片压缩字符上限、抽检比例以及需重点审视触发的特殊文字符号。
- **检索与上下文预算（`retriever`）**：选择分配策略（`budgeted` / `longest` / `full`），设定单次召回的最多卡片数、最大字符上限（`max_chars_compact` / `max_chars_json`）、实词预留名额与单类最大槽位数。

如需接入非双栏版面（如三栏表册、电子卷册或 HTML 词表），在 [`src/tome_distill/adapters.py`](./src/tome_distill/adapters.py) 中继承 `LayoutAdapter` 基类实现自定义适配器即可。

**已知使用边界**：
- 定位为**后置结构化精校与知识库编译检索层**，默认假定上游已完成基础页面文本与边界框提取；若面对歪斜扫描件或手写古籍，需先在前端进行纠偏与基础文字识别。
- 实际召回与防错效果依赖于用户在 `DomainProfile` YAML 中补充目标领域的保护字表、常见停用字与自定义复合词表。
